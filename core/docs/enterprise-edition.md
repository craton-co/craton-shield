# Craton Shield Enterprise Edition

## Overview

Craton Shield is available in two editions:

| Feature | Core (Apache-2.0) | Enterprise (BSL-1.1) |
|:---|:---:|:---:|
| CAN/Ethernet IDS | Yes | Yes |
| Software crypto (RustCrypto) | Yes | Yes |
| Network firewall | Yes | Yes |
| OTA validation (TUF) | Yes | Yes |
| Secure boot (software TPM) | Yes | Yes |
| Event logging (HMAC chain) | Yes | Yes |
| Policy engine | Yes | Yes |
| Compliance reports (IEC 62443, ISO 21434, IEC 62304) | Yes | Yes |
| Linux HAL (SocketCAN, raw sockets) | Yes | Yes |
| Post-quantum crypto (ML-KEM, ML-DSA) | Development only | Production-ready |
| Hardware HSM integration (PKCS#11) | No | Yes |
| TPM 2.0 backend | No | Yes |
| QNX Neutrino HAL | No | Yes |
| AUTOSAR Adaptive HAL | No | Yes |
| VSOC telemetry export | No | Yes |
| Dedicated support SLA | Community | 24/7 |
| Certification assistance | Self-service | Included |

## Licensing

- **Core**: Apache License 2.0 — free for commercial and non-commercial use
- **Enterprise**: Business Source License 1.1 (BSL-1.1) — converts to Apache-2.0 after 4 years

The BSL-1.1 allows evaluation, development, and internal testing at no cost. Production deployment in series-production vehicles requires a commercial license.
